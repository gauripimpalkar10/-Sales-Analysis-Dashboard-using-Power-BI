# Sales Analysis Dashboard using Power BI

## Project Overview
This project focuses on analyzing sales data using Microsoft Power BI to create an interactive dashboard and visualize sales performance.

## Tools Used
- Microsoft Power BI
- Power Query
- Data Visualization
- Data Analysis

## Project Objectives
- Analyze sales data.
- Identify sales trends and patterns.
- Present information through interactive charts and visualizations.
- Support data-driven decision-making.

## Dashboard Features
- Interactive visualizations.
- Sales performance analysis.
- Charts and graphs for exploring sales data.
- Filters and slicers, if included in the dashboard.

## How to Use
1. Download the Power BI (.pbix) file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Explore the dashboard and its available interactive features.

## Learning Outcomes
This project helped me gain practical experience in Power BI, data visualization, and sales data analysis.
